## 🔧 Technical Info

### How It Works
- **No backend required** - Works entirely in browser
- **Mock API** - Returns test data instantly
- **Persistent session** - Stays logged in until logout
- **Automatic fallback** - Activates when backend unavailable

### Demo Mode Indicator
You'll see a purple "🎮 Demo" badge in the header when in demo mode.

### Files Created

- Updated `AuthContext.jsx` - Skips verification in demo mode
